Here are three minimal “Hello World” apps—one in each language/runtime.

### Go

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, World!")
}
```

Run it with:

```bash
go run main.go
```

### Java

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

Run it with:

```bash
javac Main.java
java Main
```

### Node.js

```javascript
console.log("Hello, World!");
```

Run it with:

```bash
node app.js
```
