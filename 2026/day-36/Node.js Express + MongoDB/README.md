Project structure
```
express-task-manager/
│
├── server.js
├── package.json
├── .env
│
├── models/
│   └── Task.js
│
└── public/
    ├── index.html
    └── style.css

```

Run it
First make sure MongoDB is running.

Then:
```
cd express-task-manager
npm install
npm run dev
```
Open:
```
http://localhost:3000
```
